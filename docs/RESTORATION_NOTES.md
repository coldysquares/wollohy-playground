# Restoration notes

The source material is deliberately treated as concept evidence, not sacred implementation.

The job is to preserve the interesting interaction idea while removing prototype residue.

## HOL-001

**Keep:** generative biosphere framing, direct seeding, multiple simulation/synthesis modes, environmental pressure controls, calm open-ended play.

**Current status:** existing GUVs deployment remains the flagship reference and is linked directly from Playground. Do not rewrite it merely to make its code resemble the other toys.

## Neon Pulse — restored build 01

The original branch already had the right arcade sentence: collect notes, dodge hazards, let audio influence the field.

The restored build makes that loop explicit:

- one horizontal player movement axis
- cyan collectibles
- pink hazards
- score + combo + integrity
- saved local best score
- mouse, touch, and keyboard control
- optional uploaded-track analysis
- optional microphone analysis
- generated collection/crash tones even without an input track
- audio changes density rather than being required to understand the game

The design is intentionally more legible and less dashboard-like than the prototype.

## Vector Soup — restored build 01

The original branch had the more unusual idea: organisms whose genomes map behavior to synthesis parameters.

The restored build keeps the toy open-ended rather than forcing it into a conventional win/lose game:

- organisms forage for nutrient blooms
- reproduction inherits a parent genome with mutation
- traits include speed, sensing radius, turn force, social attraction/repulsion, pitch, hue, and size
- environmental controls change nutrient density, lifespan, and mutation pressure
- population, generation, and drift remain visible
- a radiation event mutates the active population
- births and close encounters become synthesis events once audio is enabled
- click/touch injects temporary nutrient blooms directly into the world

This is an ecosystem/instrument, not an arcade game wearing ecosystem graphics.

## Aetheria / Cosmic Fluid / Hyper-Soup

These remain deliberately disabled until one earns a distinct job in the collection. Do not enable them simply because source files exist.

A restoration should answer two questions first:

1. What can I do here that I cannot already do in HOL-001, Neon Pulse, or Vector Soup?
2. Can a visitor discover that difference without reading a paragraph of prototype lore?
