COLLECTION CONTROL

You should never have to remember where in index.html a card lives again.

  1. Drop a standalone HTML toy in /toys, or use any live HTTPS URL.
  2. Open registry.js.
  3. Copy one object, change the words, and save.
  4. Use enabled:false to hide it. Change order to move it. Use featured:true to promote it.

  tags: ["game", "generative"],
  accent: "cyan",
  featured: false,
  enabled: true,
  embed: true,
